This directory contains Blockbench models for Millenaire's villagers. They are not used by Cle and are meant to be used by texture pack makers for visualizing textures in Blockbench.
These files were generated by the LLM Claude (claude.ai) using decompiled Millenaire code... Because I could not make sense of Minecraft's, and by extension Millenaire's, model entity code (it's offset by 24 cubic pixels on Y-axis, X direction flipped from in-game???). They were verified for accuracy in BlockBench manually.
